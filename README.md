# VoxFlow 🎙

Голосовой ввод текста для Windows: зажмите **Ctrl + Win** в любой программе,
продиктуйте на русском или английском, отпустите — текст со знаками препинания
вставится туда, где стоит курсор.

## Установка

1. Запустите `VoxFlow-Setup-<версия>.exe` (права администратора не нужны).
2. При первом запуске программа попросит бесплатный API-ключ Groq:
   зайдите на [console.groq.com/keys](https://console.groq.com/keys),
   создайте ключ (карта не требуется) и вставьте его.
3. Готово. Программа живёт в трее и запускается вместе с Windows.

## Возможности

- Распознавание русского и английского с пунктуацией (Whisper Large v3 Turbo через Groq).
- Стили: «Как есть», «Чистый текст» (без слов-паразитов), «Деловой», «Промпт для ИИ» + свои.
- Оффлайн-очередь: нет интернета — запись сохранится и распознается позже автоматически.
- История всех диктовок с поиском, статистика (слова, скорость, серия дней).
- Настраиваемая горячая клавиша, режим «переключатель», личный словарь терминов.

## Работа без интернета и VPN

Если Groq API недоступен (нет интернета, VPN отключён или заблокирован из РФ), распознавание
можно выполнять полностью локально: зайдите в **Настройки → Распознавание** и скачайте
локальный движок (~285 МБ, whisper.cpp с ускорением BLAS + квантованная модель
ggml-small-q8_0, качается один раз и работает дальше офлайн, используя все ядра CPU). Режим
**«Авто»** сам переключится на локальное распознавание, если облако не отвечает — ничего
дополнительно делать не нужно.

## Частые вопросы

**Текст не вставился, но пришло уведомление «Текст в буфере».**
Нажмите Ctrl+V — текст уже в буфере обмена.

**Антивирус/SmartScreen ругается на установщик.**
Установщик не подписан цифровой подписью (она платная). Нажмите «Подробнее → Выполнить в любом случае».

**Где мои данные?**
`%APPDATA%\VoxFlow` — настройки, история и аудиозаписи. Всё хранится только на вашем компьютере;
аудио отправляется только в Groq API для распознавания.

## Разработка

```powershell
npm install        # зависимости
npm run helper     # собрать PasteHelper.exe (нужен встроенный .NET Framework)
npm run icons      # сгенерировать иконки
npm run dev        # запуск в режиме разработки
npm test           # тесты
npm run dist       # сборка установщика в dist-installer/
```
