# Verbo для Оли — правила работы над проектом

Отдельная сборка Verbo для Оли (сестра автора). Всё, что умеет основной Verbo —
голосовой ввод в любое поле, перевод выделенного текста, чтение вслух,
распознавание текста с картинки и с области экрана, — плюс **транскрипция**:
под каждым иностранным словом показывается его произношение везде, где есть
перевод. Интерфейс только русский.

Основа — Verbo 2.4.1 (`novnik25/voxflow`, тег `v2.4.1`, коммит `000e3c4`).

## Главное правило: основной Verbo не трогать

Эта сборка живёт рядом с основной и не должна задевать её ни на компьютере,
ни в репозитории:

- **Своя «личность».** `appId com.verbo.olya`, папка данных `%AppData%\VerboOlya`,
  имя пакета `verbo-olya` (от него зависит замок единственного экземпляра),
  программа `VerboOlya.exe`, ярлыки «Verbo для Оли». Ни одно из этих имён нельзя
  возвращать к основным (`com.voxflow.app`, `%AppData%\VoxFlow`, `verbo`,
  `Verbo.exe`, `Verbo.lnk`): установка перезаписала бы основную программу,
  а `taskkill` в установщике оборвал бы её работу.
- **Свой репозиторий.** Код — `novnik25/verbo-olya` (ОТКРЫТЫЙ), установщики — в его
  Releases. В `novnik25/voxflow` и `novnik25/voxflow-releases` отсюда ничего
  не публикуется. Скрипта зеркалирования в OneDrive здесь нет намеренно: он
  делал `/MIR` в папку основного проекта и затёр бы её.
- **Репозиторий открытый** — в него не попадают ключи, файлы ключей (`*.vfk`),
  журналы и данные из `%AppData%`.

## Транскрипция — как устроена

В коде слово «транскрипция» занято распознаванием речи (`transcribe` в groq.ts),
поэтому здесь всё называется «произношением»: phonetics / pron.

| | |
|---|---|
| `src/shared/phonetics.ts` | типы, запись русскими буквами (`ipaToCyrillic`), строка для копирования |
| `src/main/core/phonetics.ts` | язык текста, деление на слова (`Intl.Segmenter`), разбор ответа модели, память слов |
| `src/main/services/phonetics.ts` | запросы к сервису: выбор модели, части по 40 слов, повторы, запасная модель |
| `src/renderer/src/components/PhoneticText.tsx` | слово и его произношение столбиком — общий для панели и окна |
| `index.ts → runTranslate` | панель перевода: значки оригинала параллельно переводу, значки перевода — после |
| `TranslatePage.tsx` | блок «Транскрипция» на вкладке «Переводчик» |

Что важно знать (всё найдено живым прогоном):

- **Словаря в программе нет намеренно.** Открытый британский словарь ipa-dict
  ставит ударение не туда (`wˈɔːtɐ`) и не знает a, I, read, London. Произношение
  даёт тот же сервис, что и перевод, — по контексту (read после yesterday — [red]).
- **`max_tokens` обязателен.** Без него сервис оценивает ответ длиннее минутного
  лимита qwen (1000 токенов ответа) и отказывает заранее, даже на двух словах.
- **Модель:** сначала qwen (0,3–1,5 с), при любом её отказе та же часть сразу
  уходит модели перевода — лимиты у них раздельные.
- **Память слов** — `%AppData%\VerboOlya\phonetics.json`, до 8000 слов. Слова с
  двумя прочтениями (read, live, close…) не запоминаются.
- **Русский текст не транскрибируется** — это родной язык.
- Ударная гласная в записи русскими буквами выделяется цветом, а не знаком над
  буквой: шрифты Windows рисуют комбинируемое ударение со сдвигом на соседнюю букву.
- Чтение, запущенное из панели перевода, не перебивается приходящими значками;
  когда оно кончается, панель перевода возвращается (`overlayAfterSpeech`).

## Как переносить улучшения из основного Verbo

Истории у репозиториев разные (здесь — снимок без истории), поэтому переносим
разницей между версиями основного:

```
git -C C:\Dev\VoxFlow diff v2.4.1 vX.Y.Z -- src tests resources scripts build > upd.patch
git apply --3way upd.patch
```

После — проверить, что не вернулись основные имена (раздел «Главное правило»),
`npx tsc --noEmit`, `npm test`, живой прогон.

## Правила проекта (общие с основным Verbo)

- **Весь текст для пользователя — по-русски и без жаргона.** Нельзя показывать
  «API-ключ», «Groq», «Whisper», «LLM», «SSML», английские ответы сервисов.
  Техническая подробность идёт в журнал, человеку — понятная фраза.
- **Иконки только SVG,** никаких эмодзи в интерфейсе.
- **Комментарии в коде и сообщения коммитов — по-русски, и объясняют ПОЧЕМУ,**
  а не что. Хороший комментарий описывает грабли, на которые уже наступили.
- `build/installer.nsh` — только UTF-8 **с BOM**, `Var` объявлять внутри макроса.
- `core/` не знает про Electron — тем и ценен, что тестируется без него.
  Обвязку Electron туда не тащить.

## Как проверять работу (это важнее тестов)

Почти все настоящие ошибки находятся **живым прогоном**, а не тестами. Поэтому:

- запускать приложение и **смотреть на результат** — скриншотами окон,
  реальными файлами, записями в журнале;
- перед релизом прогонять собранный установщик, а не только `npm run build`;
- если что-то «не воспроизводится» — сначала снять скриншот экрана: там может
  висеть окно антивируса.

Тестовый прогон рядом с основным Verbo возможен: имена и замки разные. Но
горячие клавиши у сборок одинаковые — пока обе запущены, двойной Ctrl+V
откроет панели обеих.

## Сборка и релиз

```
npx tsc --noEmit          # типы
npm test                  # тесты, идут последовательно (см. ниже почему)
npm run dist              # установщик в dist-installer/
```

Дальше: поднять версию в `package.json` → коммит → тег `vX.Y.Z` →
`git push origin main` и `git push origin vX.Y.Z` →
`gh release create vX.Y.Z dist-installer/Verbo-Olya-Setup-X.Y.Z.exe --repo novnik25/verbo-olya --title "Verbo для Оли X.Y.Z" --notes-file <файл>`.

**Заметки к релизу пишутся для Оли, а не для разработчика:** что изменилось
в её работе, без имён библиотек и внутренностей.

## Особенности машины разработчика (иначе потеряете часы)

- **`ELECTRON_RUN_AS_NODE=1` протекает из VS Code** в любой дочерний процесс.
  Electron тогда выполняет приложение как обычный скрипт Node и падает
  `Cannot read properties of undefined (reading 'requestSingleInstanceLock')`.
  Выглядит как поломка приложения, но это окружение. **Снимать переменную
  перед каждым запуском.**
- **Антивирус 360 Total Security** мешает постоянно: прогон тестов падает с
  `spawn EPERM` (потому `npm test` идёт с `--no-file-parallelism`), сборка роняет
  `EPERM` при переименовании `win-unpacked`, а упакованное приложение **зависает
  на старте** на диалоге «защита реестра», если пишется ключ автозапуска.
- Изолировать тестовый запуск подменой `APPDATA` **нельзя**: Electron берёт путь
  через Win32 `SHGetKnownFolderPath`.
- `.ps1` без BOM PowerShell 5.1 читает как ANSI — кириллица внутри ломает разбор.
  Держите скрипты на латинице либо пишите с BOM.

## Что сознательно не сделано

- Транскрипции нет у диктовки с переводом (режим «английский» на плашке): текст
  вставляется в чужое поле, и значки там испортили бы текст.
- В истории переводов транскрипция не хранится: «Подставить в поля» переводит
  запись заново, и значки появляются вместе с переводом.
- `src/renderer/src/overlay.tsx` — функция `Overlay` на ~560 строк, внутри пять
  независимых экранов. Разбор откладывается осознанно, как и в основном Verbo.
